# 0.4.1

- On first start the app downloads ZMK's board data itself, so the keyboards built into ZMK are listed in **Add a keyboard** right away.
- When Docker is missing, stopped or out of reach, the Build panel's **?** shows the command to fix it for your system, and `make design` warns at start.
- `make design` checks for Python, pip and Node 20.19 or newer first, and says how to install whichever is missing.
- Windows: double-click `start.bat` to start the app. It checks for Python and Node 20.19 or newer and says how to install them.
- Linux: Studio mode lists a keyboard port your user may not open, with the command that gives access (or, if you were added to the group already, that you need to log out and back in) and a link to Troubleshooting.
- Flash looks for the keyboard for 30 seconds.
- Linux: when the keyboard's drive is plugged in but not mounted, Flash says so and gives the command to mount it.
- Linux: when Docker is missing, the Build panel's **?** and `make design` give the install command for Arch, Ubuntu, Debian, Mint and Fedora.
- macOS: when a download from GitHub fails because Python has no certificates, the message gives the command that installs them, for Python from python.org or Homebrew.
- Windows: when the app stops with an error, `start.bat` says so instead of asking to install Python or Node.
- `make design` on Ubuntu and Debian also lists `sudo apt install curl` before the Node.js commands.
