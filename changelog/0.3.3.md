# 0.3.3

- A keyboard whose layout file lists its keys in a different order than its wiring (the Charybdis) now shows a warning under the layout menu, and the board is drawn in wiring order so each key sits where the firmware puts it. The layout menu still has the file's own order.
- Saving a keymap that has layers commented out with `/* ... */` no longer fails with "no bindings prepared for new layer". Commented-out layers were counted as real ones when a layer was added or deleted.
