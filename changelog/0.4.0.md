# 0.4.0

- **Studio mode**: edit a keyboard plugged in over USB and each change works at once, with no build or flash. Switch to it with **Firmware / Studio** in the header.
- Studio mode edits keys (with drag to swap) and adds, deletes, renames and moves layers. **Save to keyboard** keeps the changes, **Discard** drops them.
- Studio mode shows how the keyboard differs from your keymap, and **Save as variant…** turns the keyboard's state into a new variant.
- **include vile slots** in the Build panel: after one flash, Studio mode can create VileDances and change combos with no build.
- Combos have a new **Reserved** state: built into the firmware but off, so Studio mode can switch them on later.
- **Reset to flashed firmware** erases Studio's changes from the keyboard. The flash sheet warns when those changes would override the new firmware.
- Layers can be renamed and moved in Firmware mode too.
- Fixed: saving a keymap with a reserved layer could put edits on the wrong layer.
- Fixed: a variant with an external power key (`&ext_power`) failed to build.
