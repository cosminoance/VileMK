# 0.2.0

- VileMK no longer uses a separate ZMK config repo. `config/`, `build.yaml` and `.zmk/` live in the VileMK folder, and the `--repo` flag and `$ZMK_CONFIG` are gone.
- A ZMK link under the logo opens settings for which ZMK the project uses. Update fetches ZMK's board data and pins the exact commit in `config/west.yml`; `make zmk` does the same from the command line.
- **Build firmware** builds a variant with Docker and writes the `.uf2` files into `variants/<name>/firmware/`, with a live build log and a cancel button. `make firmware ARGS=<name>` does the same from the command line.
- **Flash** copies the built firmware onto the keyboard from inside the app. Connect a half with USB, double-tap reset, and click **Copy** beside its file; the app tells you when the keyboard has restarted and the cable can come out.
- Build options (include reset, add-on parts, Build firmware, Flash) are in their own **Build** panel under the Save button.
- Saving is one **Save** button. On a variant it offers **Overwrite** or **Save as…**.
- **Add a keyboard** in the sidebar lists every keyboard in ZMK and in your installed modules, and adds or removes one from the project. `python3 -m vilemk.keyboards` does the same from the command line.
- **Add a keyboard** can also fetch a keyboard module from GitHub by URL and branch or tag, pinning the exact commit. Installed modules can be updated, renamed and removed; an update checks your variations against the new version before replacing anything. `make module` does the same from the command line.
- Each keyboard in the sidebar has a **⋮** menu with **Export as picture**, **Export keymap**, **Flash firmware** and **Delete**.
- **Export keymap** saves the `.keymap` to a file or copies it to the clipboard, optionally with a comment that draws the layout with each key's position number.
- The sidebar lists only **Saved variations** and **Vendor defaults**. When a vendor ships two keymaps for a keyboard, each says which it is.
- With **compare with…** on, hovering a changed key shows what it does now and what it did before.
