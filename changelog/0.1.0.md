# 0.1.0

First tagged version.

- Read, check and view ZMK keymaps from a zmk-cli config repo.
- Keymap designer in the browser, writing back to `custom/` and `variants/`.
- Keymap export as a picture.
- Import a `.keymap` file from another config.
- The "include reset" box in the variant bar has a ? that explains what the reset build does.
- The variant bar lists the add-ons the keyboard's maker offers for each half, such as a screen. Tick the ones your keyboard has and the saved build.yaml matches. An unticked screen also turns the display off, so screenless Eyelash Sofle builds no longer fail.
